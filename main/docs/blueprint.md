# **App Name**: Student Gadget Finder

## Core Features:

- Student ID Login: Allow users to log in using their student ID.
- Gadget Recommendation Analysis: Analyze a student profile based on academic stream and usage type.
- Personalized Gadget Recommendations: Show a limited number of personalized gadget recommendations (laptops, tablets, accessories) based on AI analysis. A tool that decides when to incorporate the Student ID login info when making a suggestion.
- External Deals Display: Pull live offers from placeholder APIs.
- Deal Filtering: Filter results based on student needs (tech specs and budget).
- Light/Dark Mode: Responsive support for both light and dark UI modes.

## Style Guidelines:

- Primary color: Muted purple (#9466AC), providing a sense of intellect and sophistication relevant to student life.
- Background color: Light gray (#EDEDF2) to ensure a clean and readable interface.
- Accent color: Soft blue (#72A7D4), analogous to purple, adding contrast and highlighting important elements.
- Font: 'Inter', a sans-serif typeface with a neutral and modern appearance suitable for both headlines and body text.
- Use simple and modern icons related to gadgets and student life.
- Clean and responsive dashboard-style interface, using cards to display gadgets, ensuring seamless experience across devices.
- Subtle transitions and animations to enhance user experience, like smooth scrolling and feedback on interactions.
